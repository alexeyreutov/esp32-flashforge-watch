# Flashforge Watch для ESP32-S3

Автономный монитор штатной камеры Creator 5 Pro. Плата поднимает Wi-Fi 2,4 ГГц, выдаёт IP по DHCP и хранит настройки после перезагрузки. Во время печати в оперативной памяти находится последний JPEG. Интернет, SD-карта и вторая камера не требуются.

## Waveshare ESP32-S3-LCD-2 без сенсора

Выберите профиль `waveshare-s3-lcd-2` для платы с маркировкой **ESP32-S3-LCD-2**. На дисплее 320×240 в альбомной ориентации при запуске видны пароль сети Flashforge-Watch и адрес настроек. Подключите принтер и телефон к этой сети. На телефоне откройте http://192.168.4.1 и введите IP принтера, серийный номер и LAN check code.

Во время печати экран показывает последний кадр со штатной камеры, текущий слой и состояние детектора. Обновление происходит после очередного опроса с интервалом около трёх секунд плюс время сетевых запросов. При паузе, завершении печати или потере связи старый кадр убирается. Тревога выделяется жёлтым. Встроенная пищалка в схеме этой модели отсутствует. [Документация Waveshare](https://www.waveshare.com/wiki/ESP32-S3-LCD-2)

Сборка в PowerShell из каталога проекта:

```powershell
docker build -t flashforge-watch-pio .
docker run --rm -v "${PWD}:/project" -v "flashforge-watch-pio-cache:/root/.platformio" flashforge-watch-pio pio run -e waveshare-s3-lcd-2
```

Загрузка с компьютера через PlatformIO: `pio run -e waveshare-s3-lcd-2 -t upload --upload-port COM7`. Подставьте порт платы. Готовый образ приложения в репозитории — `flashforge-waveshare-s3-lcd-2-app.bin`. После сборки он также находится в `.pio/build/waveshare-s3-lcd-2/firmware.bin`. Для первой установки используйте команду PlatformIO выше, которая записывает также загрузчик и таблицу разделов.

## Печать и сборка корпуса для Waveshare ESP32-S3-LCD-2

Габариты собранного корпуса — **46 × 59 × 21 мм** без выступающих головок винтов. Для печати нужны две детали. Для просмотра или изменения конструкции доступны [сборка STEP](enclosure/FlashforgeWatch.step) и [параметрическая модель](enclosure/enclosure.py). Размеры платы взяты из [чертежа Waveshare](https://docs.waveshare.com/assets/images/ESP32-S3-LCD-2-details-size-4a6c9b66b697ecde2ba303c8e53c55af.webp).

### Печать

1. Загрузите в слайсер по одному экземпляру [лицевой рамки](enclosure/front.stl) и [задней крышки](enclosure/rear.stl). Единицы — миллиметры, масштаб — 100%. Габарит каждой детали на столе должен быть 46 × 59 мм.
2. Сохраните ориентацию из STL. Рамка лежит лицом на столе, её стенки растут вверх. Крышка лежит наружной стороной на столе, четыре стойки направлены вверх.
3. Для первой печати подойдут PLA или PETG, сопло 0,4 мм, слой 0,2 мм, три периметра и заполнение 20%. Поддержки выключите. Температуры возьмите из профиля вашего пластика.

### Сборка

Понадобятся четыре винта **M2×12** для платы и четыре **M2×8** для корпуса. Длины указаны от нижней поверхности головки. Расчётная посадка проверена в CAD; физическая примерка пока не проводилась.

1. Положите крышку стойками вверх. Установите на них плату экраном вверх, совместив четыре резьбовые втулки платы с внутренней группой отверстий крышки. С наружной стороны крышки вставьте M2×12. После прохождения крышки и стойки винт выступает примерно на **1,2 мм**. Наживите все четыре и аккуратно подтяните от руки.
2. Наденьте лицевую рамку, совместив широкий торцевой вырез с USB-C и кнопками. До затяжки проверьте, что крышка садится свободно, рамка не давит на стекло, штекер USB-C полностью входит и кнопки доступны через вырез.
3. Вставьте M2×8 снаружи крышки в четыре крайних угловых отверстия. Винты входят в направляющие отверстия диаметром 1,75 мм в пластике рамки. Подтягивайте их по диагонали до смыкания деталей. Подключите питание и проверьте, что окно рамки открывает всю активную область экрана.

## ESP32-S3 Mini и внешний зуммер

Для этой версии нужна ESP32-S3 с работающей PSRAM. Буферы занимают около 280 КиБ внешней памяти, поэтому вариант с 2 МБ подходит. Надпись «Mini» встречается у плат с разными модулями. Проверьте маркировку и схему своей платы. Готовый образ предназначен для QSPI PSRAM и flash от 4 МБ. Для OPI PSRAM соберите скетч с соответствующей настройкой платы.

Подключите вход IN активного зуммерного **модуля с драйвером и активной единицей 3,3 В** к GPIO4, GND к общей земле, питание к выводу с напряжением по паспорту модуля. Для отдельной двухвыводной электромагнитной пищалки нужен драйвер. Если на вашей плате GPIO4 занят, поменяйте константу BUZZER и пересоберите.

## Сборка PlatformIO в Docker

В PowerShell откройте каталог с `platformio.ini` и выполните:

```powershell
docker build -t flashforge-watch-pio .
docker run --rm -v "${PWD}:/project" -v "flashforge-watch-pio-cache:/root/.platformio" flashforge-watch-pio
```

При первом запуске контейнер скачает платформу и компилятор. Последующие запуски используют тот же Docker volume. На компьютере с установленным PlatformIO достаточно выполнить `pio run` из каталога проекта. Проект использует один скетч для обеих систем сборки.

Профиль `s3-mini-qspi` рассчитан на ESP32-S3 с QSPI PSRAM, QIO flash от 4 МБ и встроенным USB CDC. Сверьте маркировку своего модуля. Файл приложения появится в `.pio/build/s3-mini-qspi/firmware.bin`. Для установки через PlatformIO на компьютере с подключённой платой выполните `pio run -e s3-mini-qspi -t upload --upload-port COM7`, подставив свой порт. PlatformIO сам выберет адреса для загрузчика, таблицы разделов и приложения.

## Установка через Arduino IDE или готовый образ

1. В Arduino IDE установите пакет **esp32 by Espressif Systems 3.3.7**. Откройте `flashforge_watch/flashforge_watch.ino`. Файл vision.h должен находиться рядом.
2. Выберите точную модель платы или ESP32S3 Dev Module. Задайте размер flash и тип PSRAM согласно плате. Для USB через встроенный контроллер включите USB CDC On Boot. Нажмите «Загрузить».
3. Альтернативно готовый объединённый образ `flashforge-s3-qspi.bin` записывается с адреса 0x0. Пример для esptool v5: `esptool --chip esp32s3 --port COM7 write-flash 0x0 flashforge-s3-qspi.bin`. Подставьте свой COM-порт. Запись объединённого образа заменяет содержимое flash в диапазоне образа.
4. В мониторе порта на 115200 бод плата каждые 15 секунд выводит SSID, пароль и статус. Пароль генерируется при первом включении.

## Первый запуск

1. На принтере включите доступ по LAN и камеру, подключитесь к сети **Flashforge-Watch**. Посмотрите полученный IP и LAN check code на экране принтера. Порядок подключения телефона и принтера может повлиять на выданный IP.
2. Подключите телефон к той же сети, оставив подключение даже при отсутствии интернета. Откройте **http://192.168.4.1**. Введите фактический IP принтера, его серийный номер и LAN check code. Нажмите «Сохранить настройки», затем «Проверить зуммер».
3. Начните печать и через 15–30 секунд обновите страницу. Откройте «Последний кадр». Выставьте левую, верхнюю, правую и нижнюю границы зоны наблюдения в процентах от ширины и высоты изображения. Например, 20, 40, 75, 90. Оставьте в кадре основание детали и участок вокруг него. Исключите парковку головок. При сохранении настроек снова введите серийный номер и код.
4. На паузе и после завершения задания съёмка прекращается. При возобновлении, смене задания или восстановлении связи детектор заново запоминает сцену. Если после переподключения к сети ESP адрес принтера изменился, обновите IP в форме.

## Что означают сигналы

- Один длинный сигнал и **ALARM** означают устойчивое изменение изображения. При продолжающейся тревоге сигнал повторяется примерно каждые 15 секунд.
- Два коротких сигнала означают, что не удаётся проверить состояние или получить кадр, либо принтер сообщил об ошибке. Причину показывает веб-страница. Сигнал появляется после нескольких неуспешных проверок.
- **Learning scene** означает сбор исходных кадров. **Watching** означает, что текущие признаки ниже порогов тревоги. Плата только наблюдает за печатью.

## Как работает анализ

Плата опрашивает HTTP API на порту 8898 и извлекает один JPEG из MJPEG-потока на порту 8080 при статусе printing. Интервал в 3 секунды отсчитывается после окончания предыдущей проверки. Кадр декодируется в масштабе 1:8. В выбранной зоне алгоритм измеряет среднюю яркость и долю контрастных границ в каждой из 12 × 8 ячеек. После четырёх начальных кадров он ищет соседние ячейки, в которых изменение сохраняется три проверки подряд. Смещение общей экспозиции учитывается по медиане изменений яркости.

Порог тревоги — группа из пяти ячеек с изменившейся яркостью или четырёх с выросшей плотностью границ. Размеры групп видны в браузере. На первых обычных печатях посмотрите, как они меняются при смене головки, опускании стола и печати заполнения. На тёмном пластике, при бликах или малой детали чувствительность может быть низкой. Нормальный рост детали также способен вызвать тревогу. Уже существующий дефект во время калибровки может попасть в эталон. Точность на физическом принтере требует испытаний с вашего ракурса.

Файл vision_test.cpp проверяет детектор на синтетических последовательностях признаков. Проверка на компьютере: `c++ vision_test.cpp -o vision_test`, затем `./vision_test`.

Пример реализации LAN API и камеры для этой модели: [FlashforgeCreator5WebUI](https://github.com/varavut/FlashforgeCreator5WebUI).
